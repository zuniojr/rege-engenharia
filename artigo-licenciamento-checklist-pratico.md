# Licenciamento Ambiental na Prática: Checklist por Etapa e Erros que Custam Caro

Este é o **guia operacional** — direto ao ponto, sem teoria. Use como **checklist de bolso** em cada fase do seu empreendimento em Santa Catarina. No final, a **tabela de custos ocultos** de cada erro comum.

---

## FASE 0 — ANTES DE COMPRAR / ANTES DE PROJETAR

| Ação | Como Fazer | Documento Gerado | Prazo |
|------|------------|------------------|-------|
| 1. Consultar zoneamento municipal | Site prefeitura / PDDU / Lei de Zoneamento | Print/PDF da consulta + coordenadas UTM | 1 dia |
| 2. Verificar APP / Restinga / Dunas / UC | SIGSC (FATMA) + SNUC + Google Earth + topografia | Mapa de restrições (KMZ/SHP) | 3–7 dias |
| 3. Consultar CNAE x Porte x Lista FATMA | Resolução CONSEMA 98/2017 + CNAE principal | Classificação: **Dispensa / LAS / LP+LI+LO / EIA** | 1 dia |
| 4. Sondar viabilidade de água/esgoto | CASAN / SAAE / Prefeitura / Poço artesiano | Ofício de viabilidade / Outorga prévia | 15–30 dias |
| 5. **Contratar assessoria técnica (ART)** | Eng. Ambiental / Sanitarista / Florestal + ART | Contrato + ART de assessoria | Imediato |

> **Regra de ouro:** **Nunca compre terreno para empreendimento licenciado sem Fase 0 concluída.** O custo da assessoria aqui (R$ 3–5 mil) evita prejuízo de R$ 500 mil+.

## FASE 3 — OBRA (GESTÃO AMBIENTAL DE CANTEIRO)

### Checklist Quinzenal (Obrigatório no PCCA)

| Item | Verificação | Não-Conformidade = Ação Imediata |
|------|-------------|----------------------------------|
| **Erosão/sedimentos** | Caixas de contenção, barreiras, mantas, bacias | Reparar em 24h / multa órgão |
| **Efluente canteiro** | Fossa séptica / ETE compacta / licença lançamento | Lacrar ponto / contratar carro-limpa |
| **Resíduos** | Separação (A/B/C/D), MTR, destinação licenciada | Multa + embargo |
| **Ruído** | Horário (7h–19h), equipamentos silenciados, barreira | Notificação vizinhança / paralisação |
| **Poeira** | Umidificação, cercado, limpeza vias | Auto de infração |
| **Vegetação** | Cercamento APP, supressão só com autorização | Crime ambiental (Lei 9.605) |
| **Fauna** | Resgate se necessário, iluminação direcionada | TCU/MP |
| **Documentação** | ARTs, licenças, laudos, MTRs, relatórios em dia | Vistoria reprovada |

### O Que o Fiscal Verifica *In Loco* (LO)

1. **ETE funcionando** → amostra na saída = parâmetros OK
2. **Caixas de gordura/inspeção** acessíveis, limpas, sinalizadas
3. **Drenagem** sem extravasamento, bocas de lobo limpas
4. **Resíduos** armazenados corretamente (abrigo, identificação, MTR)
5. **APP/Compensação** cercada, placas, mudas vivas (>80% pegamento)
6. **Ruído** na divisa ≤ limite NBR 10151 (diurno/noturno)
7. **Documentação** exposta na portaria (licenças, ARTs, emergência)

## TABELA DOS ERROS QUE CUSTAM CARO (Custos Ocultos 2025)

| Erro | Custo Direto | Custo Indireto | Tempo Perdido | Como Evita |
|------|--------------|----------------|---------------|------------|
| **Obra sem LP/LI** | Multa R$ 5.000–1.000.000 + embargo + demolição | Processo crime, dano reputacional, financiamento negado | 6–24 meses | Fase 0 + assessoria |
| **APP/Restinga não mapeada** | Projeto arquitetônico inútil + novo estudo + compensação | Redesenho total, atraso licenciamento | 4–12 meses | Topografia + biólogo **antes** do arquiteto |
| **PCCA genérico (copiado)** | Exigência técnica + novo PCCA + vistoria extra | Obra paralisada 30–90 dias | 2–3 meses | PCCA customizado por fase |
| **ETE subdimensionada** | Nova ETE (R$ 80–300 mil) + retubulação | Multa diária lançamento irregular | 3–6 meses | EVE + dimensionamento correto |
| **Outorga de poço esquecida** | Lacração poço + caminhão-pipa (R$ 15–30 mil/mês) | LO negada, obra parada | 2–6 meses | Outorga **paralela** à LP |
| **Monitoramento fora de norma** | Nova coleta + laudo (R$ 2–5 mil) + reenvio | LO atrasada 60–120 dias | 2–4 meses | Lab. acreditado + plano amostragem |
| **Compensação não executada** | Execução forçada + multa (R$ 50–500 mil) | TCU/MP, imagem negativa | 12–36 meses | Cálculo prévio + área receptora garantida |
| **Renovação LO perdida** | Operação irregular + multa diária | Interdição, processo admin. | Imediato | Alerta 180/90/30 dias (gestão Rege) |
| **Mudança projeto sem aditivo** | Nova LI + novos projetos + vistoria | Retrabalho, multa | 3–6 meses | Gestão de mudanças formal |
| **PGRS não implementado** | Multa R$ 10–100 mil + destinação emergencial | Passivo ambiental, imagem | Contínuo | PGRS operacional desde canteiro |

## CRONOGRAMA REALÍSTICO (Exemplo: Residencial 400 m² em APP Costeira — Navegantes)

```
MÊS 1–2:    Fase 0 (viabilidade) + topografia + biólogo + contratação Rege
MÊS 2–4:    RAS + mapas + compensação + protocolo LP
MÊS 4–8:    Análise FATMA/IMA + exigências (1–2 rodadas) + LP DEFERIDA
MÊS 8–10:   Projetos executivos LI (drenagem, esgoto, PCCA, supressão, erosivo)
MÊS 10–12:  Protocolo LI + exigências + LI DEFERIDA
MÊS 12:     INÍCIO OBRA + PCCA ativo + monitoramentos iniciais
MÊS 12–22:  OBRA (10 meses) — visitas quinzenais Rege + relatórios mensais
MÊS 22:     FIM OBRA + as-built + laudos finais monitoramento
MÊS 22–24:  Protocolo LO + vistoria órgão + LO DEFERIDA
MÊS 24:     Habite-se + Averbação + Entrega pasta digital
TOTAL: ~24 MESES (vs. 36–48 meses sem assessoria)
```

## PERGUNTAS RÁPIDAS (Resposta Direta)

| Pergunta | Resposta |
|----------|----------|
| **Posso protocolar LP eu mesmo?** | Pode. Mas sem estudo técnico assinado (ART) → **indeferimento certo**. |
| **LAS serve para tudo?** | Não. Só para lista taxativa (baixo impacto). Verifique **Res. CONSEMA 98/2017 Anexo I**. |
| **Preciso de EIA/RIMA para casa de praia?** | Só se > 1.500 m² **ou** em APP **ou** loteamento. Casa isolada 300 m² em zona urbana = RAS ou LAS. |
| **Quem paga a compensação ambiental?** | Empreendedor. Valor = hectares/árvores × valor de referência (R$ 15–40 mil/ha em SC). |
| **Posso usar fossa séptica simples?** | Só se **não houver rede coletora** e **fora de APP/área de proteção de manancial**. Caso contrário → ETE + outorga. |
| **Monitoramento de efluente: posso fazer eu mesmo?** | **Não.** Lab. deve ser **acreditado pela REBLAS/INMETRO** para parâmetros exigidos. |
| **Licença municipal vale para estadual?** | **Não.** Atividades de impacto estadual (indústria, loteamento > 50 lotes, posto, APP costeira) → **FATMA/IMA**. |
| **Quanto tempo a LO vale?** | 4 a 10 anos (conforme atividade). **Renovação inicia 180 dias antes do vencimento.** |
| **Rege atende fora de Navegantes?** | Sim: **Itajaí, BC, Penha, Piçarras, Porto Belo, Bombinhas, Luiz Alves, Ilhota, Gaspar, Blumenau, Joinville, Florianópolis**. |
